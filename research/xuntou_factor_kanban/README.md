## 列说明

序号 / 因子名称 / 最小分位数超额年化收益率 / 最大分位数超额年化收益率 / 最小分位数换手率 / 最大分位数换手率 / IC均率 / IR值

## ⚠️ 口径提醒（重要）

迅投的 **IC 数值（常见 0.5~0.99）明显不是 RankIC 口径**（我方 RankIC 量级 0.01~0.05）。
看板"IC均率"应是截面 Pearson 或未标准化相关，**绝对值不可与我方指标直接对比**。
有价值的用法：
1. **因子目录本身**：412 个因子的命名与方向（很多是我方灵感池没有的，如现金流市值比、应收账款指数、心理线指标等）
2. **相对排序**：同口径下哪个因子在他们样本上表现更好
3. 换手率与超额年化同样为其自定义口径，仅参考量级
