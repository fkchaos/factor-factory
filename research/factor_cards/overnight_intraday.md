# 因子卡片：overnight_intraday（隔夜-日内拆解）

- **名称**：`overnight_intraday`
- **类别**：微观结构 / 日内反转
- **逻辑**：A 股隔夜收益显著为负、日内为正（「拔河效应」）。因子 = `-(overnight - intraday)`，做多「日内强、隔夜弱」的反转方向。
- **数据源**：日 K 的 `open` / `close`（**零新增数据源**，LocalProvider 已具备）。
- **预处理**：MAD 去极值 + 截面 Z-score（行业 / 市值中性化接口预留）。
- **前视防护**：`compute` 仅用 `as_of_date` 当日 open/close + 前一交易日 close，通过 `assert_no_lookahead` 审计。
- **实证（合成随机数据 seed=7，仅框架验证，非真实结论）**：
  - RankIC ≈ -0.003 ｜ ICIR ≈ -0.014 ｜ IC 胜率 47.3% ｜ n_obs = 780
  - 衰减（1/5/10/20 日）≈ 0
  - 分层收益（5 组）≈ 0.0002~0.0005
  - 回测：total_return 31.1% / Sharpe 0.67 / MaxDD -24.0%（随机噪声）
- **状态**：✅ 框架验证通过 ｜ ⏳ 待真实数据（Tushare/AkShare）接入后重测
- **参考**：中信建投 2025-11 隔夜-日内微观结构研报（见 `docs/RESEARCH_LOG`）

## 真实数据符号复核（2026-08-05，结论：**方向翻转后成立**）
- **拆解实证**（SZ300 2020 起 / baostock sz50 2020 起 双源交叉）：
  - overnight 成分：SZ300 RankIC **+0.024**（ICIR 9.5）→ 隔夜高开是**正**信号
  - intraday 成分：SZ300 RankIC **-0.028**（ICIR -7.4）→ 日内涨幅是**反转**（负）信号
  - 旧方向 `-(overnight-intraday)`：RankIC **-0.040**（方向反了）
  - **翻转后 `(overnight-intraday)`：RankIC +0.040 / ICIR 11.6（1日），+0.030 / ICIR 9.0（5日）** ✅
- **决策**：因子符号已翻转（factors/overnight_intraday.py，docstring 同步）。
  经济含义：做多"隔夜高开 + 日内冲高回落"（= 日内反转 + 隔夜延续合成）。
- ⚠️ **成本敏感性**：1 日反转换手极高，未扣成本 IC 很漂亮，组合回测必须含成本（二次冲击模型），
  净 alpha 可能大幅缩水——这是本因子进生产前必须过的关。
- 待办：DSR/PBO 审计（n_trials 需计入翻转前后试过的方向数）。
