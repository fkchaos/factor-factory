# 因子月报模板 · MONTHLY REVIEW

> 用途：月度评审的机器体检报告（monitor/monthly_review.py 生成）。
> 决策权在人工：看报告 → 拍板（保留/降权/停用/复活）→ 更新因子卡片。
> 首期先建基线（baseline），之后每月跑 report 与历史对比。

## 0. 元信息
- 月份：YYYY-MM
- 池子：hs800 / hs300 / 全A(50亿+) 等
- 数据源：baostock（免积分，前复权）
- 生成方式：`python monitor/monthly_review.py baseline --pool hs800`（首期）
           `python monitor/monthly_review.py report --month YYYY-MM --out research/monthly/YYYY-MM.md`

## 1. 健康度（本月 vs 全期）
| 因子 | 本月 RankIC | 全期 RankIC | 差 | 判定 |
|---|---|---|---|---|
| overnight_intraday | | | | ✅正常 / ⚠️偏弱 / ❌无数据 |
| ivol | | | | |

- 判定线：本月 IC 低于全期均值 0.01 以上 → ⚠️ 偏弱（可能衰减）；连续 3 月偏弱 → 降权候选。

## 2. 滚动衰减
- 20 日滚动 IC vs 60 日 vs 全期均值：趋势性下滑 = 信号衰减预警。
- 触发线：20 日 IC 连续 5 个交易日 < 全期均值的 50% → 告警。

## 3. 拥挤度（组合层面）
- 组合权重 HHI / 最大权重 / 多头重叠度。
- 触发线：HHI > 0.25 或单票权重 > 10% → 过度集中告警。
- 与市场风格（小盘/价值/红利）相关性漂移。

## 4. 组合归因
- 影子账户月度收益 vs 基准；两因子各贡献多少；暴露变化。

## 5. 墓地复检
- 墓地因子清单 + 复检结论（市场结构变化可能让死因子复活，每季度重测一次）。

## 6. 决策输出
| 因子 | 判定 | 依据 | 人工确认 |
|---|---|---|---|
| overnight_intraday | 保留/降权/停用 | 体检数据 | ☐ |
| ivol | 保留/降权/停用 | 体检数据 | ☐ |
| （墓地复活候选） | 复活/维持墓地 | 复检数据 | ☐ |

> ⚠️ 机器只出体检，决策必须人工。确认后更新 research/factor_cards/ 与组合权重。
