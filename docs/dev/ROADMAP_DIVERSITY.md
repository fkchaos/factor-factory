# 多样性 Roadmap · 解锁非 OHLCV 数据源（roadmap ⑤）

> 本文件回应外部审核（2026-09-08）核心指控之一：**已交付因子全 OHLCV 同源、IC 中位数≈0.007、27 对 |ρ|≥0.7 冗余**，建议引入财报/另类数据提供正交 alpha。
> 本文把"解锁非 OHLCV 数据源"从"待排期"落成**可执行排期**。工厂哲学不变（不设质量门禁、好坏交策略组筛），但**真实性（PIT/DSR）是硬门槛**——多样性解决的是"有没有正交信息"，不是"好不好"。

---

## 1. 背景与动机

- 外部审核论断：59 因子全技术/价量类、来源同质（OHLCV）；无财报/另类数据因子提供正交 alpha；IC 中位数~0.01（实测 hs300 中位 ≈0.007）。
- 已交付 59 个因子中 **57 个 OHLCV 同源**；仅 f0014a/f0015a 为财报类（且受 4 字段限制只覆盖周转天数），实质仍高度同质。
- 目标：把因子数据源从"几乎全 OHLCV"降到**多源**（财报 / 分析师预期 / 资金面 / 机构持仓 / 文本情绪 / 公司事件），使新因子与现有价量因子**低相关（正交）**，改善组合 IC 条件数。
- 复用既有闸门：全局相关矩阵（`scripts/factor_correlation_matrix.py`）+ 推进器冗余闸门会自动拦截新因子的近重复，无需另建机制。

## 3. 排期（6 个 Phase，按"正交 alpha 潜力 × 工程成本 × 数据可得性"排序）

### Phase 0 · 财报因子扩面（PIT 基建已就绪，纯模板增量，最快见效）— 第一优先
- **扩字段**：`AkShareProvider._PIT_FIELD_MAP` + `_fetch_financial_history` 补 利润表(`net_income`/`operate_profit`)、资产负债表(`total_assets`/`total_equity`)、现金流量表(`ocf`)；必要时 `eps`/分红。
- **新因子模板**（复用 `PitFinancialsService`，注入 `pit_service` 或走 `default_store` 兜底）：`EP`(net_income/PIT_mcap)、`BP`(equity/PIT_mcap)、`ROE`、`ROA`、毛利率、营收 YOY、净利润 YOY、应计(accruals)、资产周转率 —— 约 **8–12 个 f-code**。
- **集成加固（可选）**：`build_deliverable` 注入 `pit_service` + 接 `prewarm_financials`；或保留 `default_store` 兜底。
- **验收**：新因子与现有价量因子 |ρ| 中位 < 0.3（正交）；直接填补"无财报因子"指控。
- **风险**：AkShare 东财稳定性/限频；`net_income` 口径（归母 vs 总计）需 PIT 验真。

### Phase 1 · 分析师预期 / 盈余调整（强 alpha、低相关）
- **源**：Tushare forecast/eps 或 AkShare 一致预期；SUE（标准化未预期盈余）。
- **因子**：分析师盈余修正动量、一致预期变化率、SUE。
- **PIT 关键**：预期值也有"公告日"，须按 `as_of` 对齐**当时**预期（不能拿最新预期算历史，否则前视）。
- **验收**：与价量低相关；IC 稳定性。

> **2026-09-09 实测修订（Phase 1 第一小批已交付 f0073a–f0075a）**
> - 改用 **AkShare `stock_yjyg_em`（东财业绩预告）** 替代卖方一致预期：公司自身指引比卖方预期
>   更硬（有法律约束），且**带公告日 → 天然 PIT**。全历史 26 个报告期仅 3.5 分钟拉完
>   （对比财报 prewarm hs300 的 111 分钟），落单文件 parquet，无需逐票预热。
> - 🔴 **覆盖率硬约束**：hs300 内每报告期仅 **28~36%** 公司发预告 → 截面必然稀疏，
>   是数据事实不是取数 bug，禁止用前填/均值填充粉饰。年报(1231)覆盖最广、一季/三季
>   2023 年注册制后骤降（Q1 仅 200~600 家）。
> - 🔴 **预告修正动量不可实现**：同一 (股票, 报告期) 在该源中**恒为 1 条**（AkShare 已按最新
>   去重）→ 拿不到修正历史。Phase 1 原本最想要的 revision momentum 在此源上胎死腹中。
>   若要修正类信号，须换源（巨潮/万得预告修正明细），**勿在 akshare 上重复尝试**。
> - 首批结果（hs300 单池）：f0073a 预告同比 RankIC=+0.0004 / 胜率 49.4%——**几乎为零**。
>   与"PEAD 是 A 股强异象"的预期不符，可能原因：① 覆盖稀疏致中性化后稀释；② 阶梯持续
>   使信号在预告发布后长期沿用而衰减。→ 后续改进方向：改**事件窗口**（公告后 N 日衰减）
>   而非无限阶梯；或转向 SUE（用已有 PIT 财报算，覆盖率 100%）。

### Phase 2 · 资金面另类（龙虎榜 / 大单 / 分单 / 两融）
- **源**：龙虎榜 akshare lhb（上榜原因、机构净买席位）；分单资金流 akshare fund_flow（主力/超大单净流入）；两融（融资余额变化、融券）。
- **因子**：机构龙虎榜净买占比、主力资金连续流入、融资余额增速。
- **PIT**：日度数据按交易日对齐即可。

### Phase 3 · 机构持仓 / 聪明钱（基金季报持仓 / 北向）
- **源**：基金季报重仓变动、机构持股比例变化；北向（沪深港通）持股变化。
- **PIT 难点**：季报低频，须按披露日阶梯对齐，**不能提前用**。
- **因子**：机构增持、北向连续净流入。

### Phase 4 · 文本 / 情绪（研报文本 + 舆情 + LLM/FinBERT + iVIX）
- **源**：研报文本/舆情情感（FinBERT/LLM 推理）；iVIX 中国波指（波动率预期）。
- **因子**：研报情感动量、新闻异常情感。
- **归口**：iVIX 为市场级状态标量，更适信号线 s-code 而非截面因子。
- **成本**：LLM 推理批处理 + 缓存。

### Phase 5 · 公司事件（业绩预告 / 增减持 / 解禁）
- **源**：业绩预告、增减持、解禁日历。
- **因子**：预告超预期、减持压力、解禁冲击。
- **归口**：多归信号线（事件状态）或截面因子。

## 4. 执行纪律（复用现有管线，不另起炉灶）

- 每 phase 走统一链路：**数据适配层 → PIT 审计（`nunique()` 验字段是否随时间变 / 是否未来污染）→ 因子模板 → 经全局相关矩阵 + 推进器冗余闸门出包 → 看板/记忆更新**。
- 推进器 `automation-1786017033599` 维持 K=6/晚 drain 价量积压；新源因子在数据源接入后由推进器 drain 或单独 cron。
- **真实性硬门槛不动**：PIT 验真 + DSR/PBO；不设 |IC|≥0.03 质量门禁（好坏交策略组）。
- C 桶 21 条"数据源阻塞"灵感按 phase 复活（见 `docs/dev/BACKLOG_TRIAGE_2026-09-01.md` C 桶）：i20260805-001/002（盈余公告日）、i20260806-004（PIT 利润表）、i20260806-011（龙虎榜）、i20260806-012（两融）、i20260818-003/004/005（龙虎榜/事件/另类）、i20260820-033（现金流 SUE）、i20260824-001/003/004/005/006/008/009（预期/财报多科目/分单/iVIX）、i20260827-002/004/007/008（两融折算/研报文本/基金持仓）等。

## 5. 成功指标

- **数据源分布**：OHLCV 占比 100%（实质 57/59）→ 目标 <60%（财报/预期/资金/文本多源）。
- **正交性**：新因子与现有价量因子 |ρ| 中位 < 0.3。
- **组合条件数**：现有 27 对 |ρ|≥0.7 多为价量内部；新源加入后整体条件数改善。
- **交付计数**：Phase 0 首批 8–12 个财报 f-code；后续每 phase 增量。
